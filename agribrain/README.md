# AGRI-BRAIN

This directory holds the implementation of the AGRI-BRAIN system:

- `backend/` -- FastAPI backend (port 8100), MCP and institutional retrieval layer, decision engine, chain client.
- `frontend/` -- React + Vite dashboard (port 5173).
- `contracts/` -- Solidity smart contracts (Hardhat).

- [Repository README](../README.md): project overview, scope and documentation map.
- [HOW_TO_RUN.md](../HOW_TO_RUN.md): install, run and test the application.
