# Published results

The tables here are the subset of the study's frozen analysis outputs that the paper reports. [`MANIFEST.json`](MANIFEST.json) gives, for each table, the source file's hash and row count, the rows kept and the published file's hash. The [data guide](../../docs/DATA.md) explains the mode and setting codes and what each table holds.

Check them with `python scripts/verify_package.py` from the repository root.
