# AGRI-BRAIN methodology-alignment candidate

This candidate replaces several simulation, statistical, ablation, forecast,
and validation semantics from the historical `2fd7bff` release. Accordingly,
the historical evidence archive is not evidence for this source and no old
numerical result is carried forward.

Release notes for a public submission may be finalized only after one of two
validated evidence paths completes: (1) a fresh, complete simulation run from
one clean source identity, or (2) an authorized publication-only recovery from
preserved completed simulation workers whose raw inputs and accounting are
verified without rerunning simulations. The current package uses path (2).

Its final notes must record the simulation source commit/tree, publication
code commit/tree, core and structural run tags, failed and replacement
publisher job identifiers, dependent finalizer job identifier,
`simulation_rerun: false`, executed and retained counts, recovery receipts,
combined `READY` status, archive member counts/sizes/SHA-256 values, and only
the claims supported by that validated evidence.

The benchmark is synthetic. Waste fraction per routing opportunity, modeled
emissions indicator, social-performance proxy, and severity-weighted RLE are model
outputs rather than field measurements; the social-performance proxy is not
demographic equity.
