# Generated publication evidence

No current publication evidence is committed to this source snapshot. The
historical `2fd7bff` archive was generated by superseded simulation semantics
and must not be extracted here or attributed to the methodology-aligned code.

After inspecting an archive and extracting a validation copy into this
directory, use the following commands for fresh single-provenance evidence:

```bash
python mvp/simulation/analysis/verify_manifest.py --strict-commit
python mvp/simulation/validation/validate_publication_artifacts.py
```

For authorized recovery, run from the exact publication-code checkout and pass
its canonical extracted receipt explicitly:

```bash
RUN_TAG=<run-tag>
RECOVERY_RECEIPT="mvp/simulation/results/publication_recovery_receipts/$RUN_TAG.json"
python mvp/simulation/analysis/verify_manifest.py --strict-commit \
  --recovery-receipt "$RECOVERY_RECEIPT"
python mvp/simulation/validation/validate_publication_artifacts.py \
  --recovery-receipt "$RECOVERY_RECEIPT"
```

Keep the new archive unchanged. Use a separate extracted copy for
validation, figure regeneration, or additional analysis.

The validated publisher also emits `h2_directional_evidence.csv`, the exact
20-row confirmatory H2 table, and `transport_emissions.{png,pdf}`. The latter
contains the modeled routing-emissions outcome only. Decision-path Green-AI
activity estimates and separately labelled fixed-step proxies remain in the
per-seed envelopes and `benchmark_summary.json`; they are not transport carbon
and are not whole-job hardware telemetry.
